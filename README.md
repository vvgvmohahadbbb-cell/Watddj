# همسة (تطبيق أندرويد)
غلاف WebView يفتح سيرفر همسة. كل push إلى main يبني APK موقّعاً ثم ينشره تلقائياً في server/app.apk (رابط /download).
- الإشعارات: أنشئ مشروع Firebase وضع الملف google-services.json داخل مجلد app/ (انظر الشرح). وضع محتوى مفتاح الحساب الخدمي في متغير FIREBASE_SA على Render.
- hamsa.jks هو مفتاح التوقيع (ثابت كي تنجح التحديثات). لا تغيّره، واجعل المستودع Private.
