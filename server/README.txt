همسة — تطبيق مراسلة خاص
1) في Termux (مرة واحدة):  pkg install nodejs openssl-tool net-tools termux-api
2) فك الضغط ثم:  cd hamsa && sh start.sh
3) افتح العنوان الظاهر من أي هاتف على نفس الواي فاي (اقبل تحذير الشهادة) ثم "إضافة للشاشة الرئيسية".
- لا تغلق Termux، وفعّل "عدم تحسين البطارية" له.
- البيانات: db.json (حسابات + رسائل معلّقة مشفرة تُحذف عند التسليم أو بعد 3 أيام).
- للتحديث: غيّر VERSION في server.js و VER في index.html.
- للوصول من خارج البيت: استعمل Tailscale على الأجهزة كلها.

- النسخة 1.2: السيرفر يمرّر النص فقط. الصور والملفات والصوت والمكالمات تنتقل مباشرة بين الهاتفين (WebRTC) من نت المستخدمين، والسيرفر لا يستهلك منها شيئاً.
- إن فشل الاتصال المباشر بين شبكتين مختلفتين (شبكات الجوال أحياناً) استعمل Tailscale على الأجهزة.

- من شبكات مختلفة: pkg install cloudflared ثم  sh start.sh public  (يعطيك رابط https عام. يتغيّر كل مرة تشغّل؛ للرابط الثابت استعمل Tailscale أو نفق Cloudflare باسم نطاقك).
- إن فشل الاتصال المباشر بين الهاتفين، الملفات تمرّ تلقائياً عبر السيرفر (بدون تخزين). للمكالمات الصعبة أضف TURN: TURN_URL=turn:host:3478 TURN_USER=u TURN_PASS=p node server.js

- تحديث التطبيق نفسه (APK): ضع app.apk الجديد بجانب server.js وغيّر الرقم في apk.json لنفس رقم البناء N؛ التطبيقات القديمة تعرض نافذة "يوجد تحديث".

- Render + Upstash (بدون بطاقة): انظر الرد. متغيرات البيئة: PLAIN=1  UPSTASH_URL=...  UPSTASH_TOKEN=...  NO_RELAY=1
